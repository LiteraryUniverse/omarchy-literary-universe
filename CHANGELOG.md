# Changelog

## 0.1.0

First public release, for Omarchy 4 Quattro (tested on 4.5.0).

- Bar widget with scratchpad capture, diary, personal tasks, continue writing, the latest three notifications and the latest LU blog article.
- OAuth login in the browser with separate permissions; tokens stay in the OS keyring.
- Optional desktop banners for diary reminders, messages and releases. Banners carry a fixed label, never notification text.
- Covers are downloaded by the helper with size and dimension limits and shown from a private local copy.
- 50 Omarchy languages.
