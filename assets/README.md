# Literary Universe mark

`lu-mark.png` is the official LU mark, copied unchanged from
[`app/public/images/icons/web-app-manifest-192x192.png`](https://github.com/StorytellerCZ/Literary-Universe/blob/develop/app/public/images/icons/web-app-manifest-192x192.png).

`LuLogo.qml` paints the mark's original alpha silhouette with the current Omarchy
color. The bar uses its foreground/active color and the panel header uses the
accent. The image is bundled locally; displaying it makes no network request.
